Agent function-calling evaluation

A human-in-the-loop evaluation platform for reviewing how AI agents choose tools, supply arguments, and complete a user's request.

The problem

A plausible response does not guarantee that an agent used the right tool or supplied grounded arguments. Reviewers need to assess the actions behind an answer as well as the answer itself.

My contribution

I designed and developed a quiz-style review interface in which graders compare a user query with the assistant's tool usage. A structured framework of nine to ten questions captures judgments about tool selection, parameter accuracy, and response completeness.

What the platform produces

The workflow captures granular human feedback as labeled evaluation data for an RLHF pipeline. It makes distinct failure modes visible instead of reducing every response to a single overall judgment.

Evaluation dimensions

  • Tool selection: Did the assistant select an appropriate function for the request?
  • Parameter grounding: Were arguments supported by the user's intent and available context?
  • Completeness: Did the resulting response address the request?

Related experience

This project sits alongside my work leading an AI evaluation pod at Turing and evaluating coding-agent behavior at Mindrift. The focus is consistent review, useful feedback, and understanding where an agent's reasoning or actions break down.
